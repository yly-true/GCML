# 轻量化 Landmark GCML

本仓库在固定地标图上学习 Q/V/W/G，并在高维潜空间生成随机候选轨迹完成导航。

```bash
conda activate tf215_gpu
pip install -r requirements.txt
python train.py
python test.py
```

代码入口：

```text
train.py               创建地图、采集buffer、训练Q/V/W/G
test.py                加载模型并运行测试
evaluation/            测试、消融和可视化
curve/                 离散路径的可选曲线化后处理
outputs/models/        模型
outputs/figures/       图片
outputs/data/          图片对应的JSON数据
```

全部参数放在相应文件顶部，不使用命令行参数。

## 1. 训练

### 1.1 地图、状态和动作

`World._map()`创建100×100布尔栅格。`False`表示自由空间，`True`表示墙体。三条横墙和三条竖墙将地图分为4×4共16个房间，`BLOCKED_PASSAGES`在训练前固定封闭4个通道。

每个房间放置2×2共4个内部节点，房间之间保留通道节点：

```text
内部节点：16 × 4 = 64
开放通道节点：20
状态总数：N = 84
有向动作总数：A = 208
```

状态是离散节点编号i，其潜状态为Q的第i列：

$$
s_i=Q_{:i}\in\mathbb R^d.
$$

动作不是“上、下、左、右”，而是一条有向边：

$$
a:i\rightarrow j.
$$

同一条连接的两个方向属于两个动作。房间内节点连接成小方格；跨房间必须经过通道节点。建图后会检查所有边不穿墙、所有保留通道至少连接墙两侧、整张图保持连通。

### 1.2 随机轨迹buffer

训练数据通过随机游走获得：

1. 随机选择起始节点。
2. 从当前节点的真实可执行动作中随机选择一个。
3. 执行动作并记录下一节点。
4. 连续执行100步，组成一条轨迹。
5. 至少收集200条轨迹；如果尚未覆盖全部节点和动作，则继续收集，最多500条。

buffer包含：

```text
buffer_o     [轨迹数, 100]：当前节点
buffer_a     [轨迹数, 100]：动作编号
buffer_next  [轨迹数, 100]：下一节点
```

每条样本满足 $i\xrightarrow{a}j$。训练开始前要求节点覆盖率和动作覆盖率均为100%。每轮训练随机抽取16条完整轨迹，再展平为一步转移样本。

### 1.3 四个矩阵

| 矩阵 | 形状 | 作用 |
|---|---|---|
| $Q$ | $d\times N$ | 将离散节点编码为潜状态 |
| $V$ | $d\times A$ | 表示动作在潜空间中的位移 |
| $W$ | $A\times d$ | 将目标方向转换为动作效用 |
| $G$ | $A\times d$ | 从潜状态预测动作软可执行性 |

当前主模型 $d=128$。初始化为：

$$
Q\sim\mathcal N(0,1),\qquad
V,W,G\sim\mathcal N(0,0.1).
$$

没有额外加入Q白化、训练后固定阶段或人工最短路监督。

### 1.4 Q和V：学习状态转移

对一步转移 $i\xrightarrow{a}j$：

$$
s_t=Q_{:i},qquad
\hat s_{t+1}=Q_{:i}+V_{:a},qquad
s_{t+1}=Q_{:j}.
$$

预测残差为：

$$
\delta=Q_{:j}-Q_{:i}-V_{:a}.
$$

代码按节点和动作聚合batch中的重复样本，然后更新：

$$
Q_{:j}\leftarrow Q_{:j}-\eta_Q\delta,qquad
V_{:a}\leftarrow V_{:a}+\eta_V\delta.
$$

目标是得到：

$$
Q_{:j}\approx Q_{:i}+V_{:a}.
$$

因此动作位移可以多步累加：

$$
\hat s_T=Q_{:i_0}+\sum_{t=0}^{T-1}V_{:a_t}.
$$

这使rollout可以直接在潜空间中进行，而不必在二维地图里逐步查询位置。

### 1.5 W：学习动作效用

动作a的真实潜方向为：

$$
d_a=Q_{:j}-Q_{:i}.
$$

代码使用：

$$
W_{a:}\leftarrow W_{a:}+\eta_Wd_a^\top.
$$

规划时，目标方向为 $s^*-\hat s_t$，所有动作效用为：

$$
u_t=W(s^*-\hat s_t).
$$

$u_{t,a}$越大，表示动作a越符合当前到目标的方向。W输出的是方向效用，不是Q-learning中的状态动作价值，也不是最终的整条轨迹评分。

例如目标方向为 $[2,1]^\top$，一个动作方向近似 $[1,0]^\top$，另一个近似 $[-1,0]^\top$，则前者与目标方向点积为正，更容易获得较大效用。

### 1.6 G：学习动作可执行性

对节点i定义真实动作可执行性：

$$
f_i[a]=
\begin{cases}
1,&\text{动作a从节点i出发},\\
0,&\text{否则}.
\end{cases}
$$

G预测：

$$
\hat g_i=GQ_{:i}.
$$

更新为：

$$
G\leftarrow G+\eta_G(f_i-GQ_{:i})Q_{:i}^\top.
$$

G输出实数软门控，不是0/1分类结果，也不是概率。理想情况下可执行动作接近1、不可执行动作接近0，但实际值可能小于0或大于1。

例如：

$$
GQ_{:i}=[0.96,0.03,-0.02]^\top.
$$

这只能解释为动作0门控较强，不能解释为96%的执行概率。

### 1.7 训练过程和输出

主要训练参数：

```text
LATENT_DIM = 128
EPOCHS = 1000
BATCH_TRAJECTORIES = 16
ETA_Q = 0.1
ETA_V = ETA_W = ETA_G = 0.01
```

训练同时保存8、16、32、64维模型用于维数消融，并在相同buffer上额外训练64/128维的种子1和2，用于稳定性测试。

运行 `python train.py` 生成：

- `outputs/models/gcml_model.npz`：主模型、初始矩阵、buffer和消融模型。
- `outputs/models/gcml_repeats.npz`：额外训练种子。
- `outputs/figures/01_training_loss.png`：Q/V转移误差、W方向误差、G可执行性误差。

训练损失下降只说明固定训练图上的代数目标得到优化，不能单独证明导航必定成功或模型能泛化到新地图。

### 2.2 连续起终点和离散地标

测试的起点和终点是自由空间中的连续坐标。程序分别寻找直线可见地标，再选择总代价较小的起终节点。连续坐标只负责起点到首节点、末节点到终点的挂接；GCML主体仍在离散节点和高维潜状态中规划。

### 2.3 CML

CML只看当前一步：

$$
u=W(Q_{:\mathrm{goal}}-Q_{:\mathrm{current}}),qquad
a=\arg\max_{a\in\mathcal A(i)}u_a.
$$

它只在当前真实可执行动作中选择，不使用G、噪声或多步想象。

### 2.4 GCML rollout

每条候选从当前真实状态开始：

$$
\hat s_0=Q_{:\mathrm{current}},\qquad s^*=Q_{:\mathrm{goal}}.
$$

每个想象步骤执行：

$$
u_t=W(s^*-\hat s_t),
$$

$$
\bar u_t=\frac{u_t}{\max(\|u_t\|_2,10^{-9})},
$$

$$
e_t=g_t\odot(\bar u_t+\epsilon_t),qquad
a_t=\arg\max_a e_{t,a},
$$

$$
\hat s_{t+1}=\hat s_t+V_{:a_t}.
$$

第一步使用当前节点的真实可执行动作作为门控；第二步以后只用 $g_t=G\hat s_t$，不查询真实图。因此多步rollout发生在128维潜空间，而不是二维地图。

每条候选最多想象32步。如果：

$$
\|\hat s_t-s^*\|_2\le0.8,
$$

则记为潜空间到达。100条候选生成后：

1. 优先选择到达候选。
2. 多条都到达时选择想象步数最少的。
3. 全部未到达时选择终点潜空间残差最小的。
4. 同分时取先生成的候选。

### 2.5 MPC式执行与失败

GCML只执行最佳候选的第一个动作，然后重新观测、重新生成100条候选：

```text
观测真实节点 → 高维rollout → 选择最佳候选
→ 只执行首动作 → 观测新节点 → 重新rollout
```

所以它与MPC的滚动时域思想相似。候选后续动作不会一次全部执行。

当前没有fallback。64次真实决策内未到达、没有可执行首动作或进入循环都会保持失败，不调用最短路补齐。曲线模块也只处理已经成功的路线。

### 2.6 测试内容

完整测试包含：

- 30组GCML/CML随机导航。
- 候选数量和rollout horizon实验。
- 潜维数、噪声和到达阈值消融。
- 多训练种子与想象真实性测试。
- Q/V/W/G矩阵结构诊断。
- 42组数学、边界和只读性检查。

当前保存结果中，导航图为GCML 30/30、CML 15/30；另一批30组基准中，GCML使用100条候选时为100%，CML为30%。这只是当前固定地图和任务采样的实测结果。

### 3.2 图06：想象可靠性

图06回答：潜空间认为到达，是否真的对应一条有效动作序列？

| 位置 | 内容 | 读法 |
|---|---|---|
| 左上 | 固定阈值与归一化阈值下的真实成功率 | 越高越好 |
| 右上 | 潜空间到达中的虚假到达比例 | 越低越好 |
| 左下 | 3个训练种子的成功率 | 点高且误差棒短更好 |
| 右下 | 3个训练种子的SPL | 越接近100越好 |

真实有效到达要求：想象动作逐步放回真实图后，每一步都可执行，并且最终节点等于目标。这个真实图检查只用于测试统计，不参与rollout选择。

当前8维固定阈值下，成功率33.3%，但潜空间到达中的98.8%是虚假到达；归一化阈值后虚假到达降为6.2%。128维、噪声0.18时成功率100%，但仍有12.7%的潜空间到达不是真实有效到达。

结论：导航成功不代表想象完全正确。GCML因为每次只执行第一步并重新规划，可以容忍一部分错误想象。

### 3.3 图07：数学自检

图07不是导航成功率。

- 左上：100条真实有效路径连续累加32个V后的终点误差。蓝线必须低于理论上界。当前最大误差0.001317，上界0.007839。
- 右上：G在不同潜维数下的理论最低误差与实际误差。低维受 $\operatorname{rank}(GQ)\le d$ 限制，不能无误差恢复全部动作可执行性。
- 左下：潜状态有误差时G会放大多少。蓝点应满足：

$$
\|G\Delta s\|_2\le\|G\|_2\|\Delta s\|_2.
$$

- 右下：42组实现检查汇总，包括图连通、buffer连续、候选排序、阈值边界、死路、循环、动作重编号、潜空间旋转/缩放和推理只读。

42/42只说明这些公式和程序边界通过，不代表所有导航任务都成功。

### 3.5 图09：动作选择解释

图09记录一次真实推理的数值：

1. 首步真实可执行动作的W效用、噪声、门控和得分。
2. 第二想象步中G对动作的门控。
3. 完整候选的到达状态、长度、残差和排名。
4. 最终选中的候选及其首动作。

单步动作得分为：

$$
e_{t,a}=g_{t,a}(\bar u_{t,a}+\epsilon_{t,a}).
$$

G是实数软门控，不是概率。候选内动作由该得分逐步生成，完整候选最终再按“到达优先、到达者选短、未到达者选残差小”排序。

### 3.6 图10：曲线化

图10由独立模块生成：

```bash
python -m curve.demo
```

当前一次显示12组案例。蓝色虚线是GCML成功后的离散路线，橙色实线是曲线。标题中的“路径点10→3”表示10个原始点被删减为3个安全必要转折点。

处理分两步：

1. `simplify_path()`删除有安全直线视线的冗余节点，不能跨墙。
2. `smooth_path()`对每个相邻点对使用三次Hermite多项式，并共享连接点切向量。

$$
c_i(t)=(2t^3-3t^2+1)p_i+(t^3-2t^2+t)m_i
+(-2t^3+3t^2)p_{i+1}+(t^3-t^2)m_{i+1}.
$$

当前参数为 `CASES=12`、`SAMPLES=40`、`TENSION=0.8`。每段曲线都会检查墙体净空；不安全时将切向量减半并重试，仍不安全则报错。

公开接口：

```python
from curve import curve_between, simplify_path, smooth_path

segment = curve_between(a, b, ta, tb, samples=40)
key_points = simplify_path(points, free)
curve = smooth_path(key_points, 40, 0.8, free)
```

图10只是几何平滑，不是连续控制。它没有速度、加速度、转弯半径或机器人动力学约束，也不会改变GCML的Q/V/W/G和动作选择。
